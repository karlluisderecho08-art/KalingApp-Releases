## Installing

KalingApp isn't from the Play Store, so Android asks you to allow installs
from your browser or files app. That is expected.

1. **If version 1.2.1 or older is on your phone, uninstall it first**
   (press and hold the KalingApp icon and tap **Uninstall**, or go to
   Settings → Apps → KalingApp → Uninstall). Version 1.3.0 or newer
   installs over without uninstalling.
2. Tap the download link above, then **Download**.
3. Open the downloaded file. If Android says installs from this source are
   blocked, tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**, open KalingApp, and log in.

From 1.3.0 on, every version is signed with the same KalingApp key, so later
updates install over this one without uninstalling.

## Notes

Milk volumes throughout the app are millilitres. The admin console displays
facility stock in litres, but that is display formatting over the same stored
millilitres — there is no second unit anywhere in the system.

The app talks to the live backend on Render, which sleeps after 15 minutes of
inactivity on the free plan. The first request after a quiet period can take
10–30 seconds while the server wakes up. That is expected, not a failure.

This repository holds built artifacts only. The application source lives in a
separate, private repository.
